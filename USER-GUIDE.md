# User Guide

## Building
- Select **Build** tool and double-click the canvas to place a 1x1 brick (snaps to grid).
- Switch tools from the left toolbar: Delete, Rotate, Move, Scale, Custom.
- Toggle snapping from the toolbar.

## PDF assisted mode
1. In **PDF Import**, upload LEGO instructions (PDF, <100MB).
2. The first page is processed and COCO-SSD suggests bricks; suggestions count appears.
3. Navigate steps with Prev/Next and place suggested bricks using **Auto-build step**.

## Saving & Loading
- Use **Save** to persist to localStorage.
- **Load** restores the last autosave.
- Autosave runs every 30s.

## Export
- Use **Export** to download the current scene as `.lego.json`.

## Keyboard shortcuts
- Standard browser zoom applies; scene interactions rely on mouse + transform controls.
